# Data-Center Capacity Planner

Size a spine-leaf fabric: servers per leaf, uplinks per spine-leaf pair,
oversubscription ratio, and realistic bisection-bandwidth estimates from your
own numbers.

**Live version:**
[allaboutitinfrastructure.com/tools/dcap/](https://allaboutitinfrastructure.com/tools/dcap/)

**Run it:** open `index.html` in any browser. Single file, no dependencies,
works offline. Everything is computed locally — nothing leaves the page.
