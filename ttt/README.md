# Tick-to-Trade Latency Calculator

Build the full path from market-data tick to order on the wire and see the
waterfall: propagation delay, serialization, switch hops, feed handling, and
application processing — each component itemized so you can see where the
microseconds go.

**Live version:**
[allaboutitinfrastructure.com/tools/ttt/](https://allaboutitinfrastructure.com/tools/ttt/)

**Run it:** open `index.html` in any browser. Single file, no dependencies,
works offline. Everything is computed locally — nothing leaves the page.
