# Availability / SLA Calculator

Translate an SLA percentage into real downtime (per year, month, week, day),
and combine component availabilities to see what a chain of dependencies
actually delivers — reliability multiplies, it doesn't average.

**Live version:**
[allaboutitinfrastructure.com/tools/sla/](https://allaboutitinfrastructure.com/tools/sla/)

**Run it:** open `index.html` in any browser. Single file, no dependencies,
works offline. Everything is computed locally — nothing leaves the page.
