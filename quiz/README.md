# Subnet Quiz

Endless CCNA-style subnetting practice: network addresses, broadcast
addresses, host counts, and VLAN-range questions, each with a worked
explanation so a wrong answer still teaches.

**Live version:**
[allaboutitinfrastructure.com/tools/quiz/](https://allaboutitinfrastructure.com/tools/quiz/)

**Run it:** open `index.html` in any browser. Single file, no dependencies,
works offline. Everything is computed locally — nothing leaves the page.
