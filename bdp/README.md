# Bandwidth-Delay Product Calculator

Size TCP windows for the link you actually have. Enter bandwidth and RTT —
get the bandwidth-delay product, the window needed to fill the pipe, Mathis
throughput bounds under packet loss, packet-per-second rates, and
file-transfer time estimates.

**Live version:**
[allaboutitinfrastructure.com/tools/bdp/](https://allaboutitinfrastructure.com/tools/bdp/)

**Run it:** open `index.html` in any browser. Single file, no dependencies,
works offline. Everything is computed locally — nothing leaves the page.
