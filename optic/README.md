# Optical Link Budget Calculator

Will this fiber run survive the physics? Enter fiber type (OS2/OM3/OM4/OM5)
and wavelength with attenuation presets, distance, TX launch power, RX
sensitivity, connector pairs, and splices — get total channel loss, power
budget, link margin with a green/amber/red verdict, per-element loss
breakdown, and max reach.

**Live version:**
[allaboutitinfrastructure.com/tools/optic/](https://allaboutitinfrastructure.com/tools/optic/)

**Run it:** open `index.html` in any browser. Single file, no dependencies,
works offline. Everything is computed locally — nothing leaves the page.

Verify transceiver launch power and receiver sensitivity against your
datasheet — presets are typical values, not guarantees.
